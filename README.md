
# OpenStack & Kubernetes Homelab Tutorials

A practical, hands-on learning repository for building and operating **OpenStack and Kubernetes environments** in a lab setting.

This repository documents my personal experience with designing, deploying, troubleshooting, and maintaining infrastructure platforms using technologies such as:

- OpenStack
- Kubernetes
- Kolla-Ansible
- Ceph
- Linux
- Docker
- Ansible
- GitLab
- Networking and storage components

The goal is to provide clear, reproducible, and practical tutorials for infrastructure engineers, system administrators, DevOps engineers, and anyone interested in learning cloud platforms through real-world implementation.

> **Important:** All tutorials and configurations in this repository are based on my own hands-on experiments and practical experience. Every procedure has been tested and executed by me in a lab environment.

---

## Purpose

I created this repository to share what I have learned while working with OpenStack and Kubernetes.

By publishing these tutorials and sharing my experience, I hope to:

- Make complex infrastructure technologies easier to understand
- Help beginners build their first OpenStack lab
- Provide practical guidance for engineers preparing for production environments
- Document real deployment challenges and troubleshooting experiences
- Contribute positively to the open-source community
- Continue improving my own technical knowledge through documentation and knowledge sharing

This repository is part of a larger series of tutorials that I am gradually preparing and publishing. New sections, improvements, troubleshooting notes, and advanced configurations will be added over time.

---

## Tutorial Roadmap

The tutorials are organized into progressive stages. Each stage is designed to build upon the knowledge and experience gained in the previous one.

### Stage 1: Simple OpenStack Lab

A beginner-friendly, all-in-one OpenStack lab environment designed for learning and experimentation.

This stage focuses on:

- Understanding the basic OpenStack architecture
- Preparing the operating system and prerequisites
- Installing OpenStack using Kolla-Ansible
- Deploying an all-in-one OpenStack environment
- Accessing OpenStack services
- Performing basic administrative operations
- Creating networks, images, flavors, projects, and instances
- Practicing common troubleshooting procedures
